# 课程项目中的思维导图模块

本目录来自 `mindmap-v0.1 (3)/mindmap-v0.1 (3)/mindmap-v0.1`。不包含该副本的个人导图、任务、学习背景或 API 配置。生成、全文规划、结构复核、主题配色、分组及自动整理均由原导图模块实现。

## 运行与数据

通过项目根目录“启动课程网站.bat”启动即可。现有网站进程同时提供 `/mindmap/`，无需另开 8794/8796。停止课程网站时也停止此模块；生成子进程随父进程断开而中止，原有任务恢复流程保留。

- 正式导图与媒体、草稿：`back/data/mindmap/maps/`。
- 后台任务与原件：`back/data/mindmap/lecture-tasks/`。
- 学习背景：`back/data/mindmap/student-profile.json`。
- AI：只在服务端读取课程已保存的加密配置，不创建第二份 Key 配置，不向浏览器返回密钥。

共享课程顶栏 AI 设置。资料详情“生成导图／编辑导图”和资料编辑窗口“打开导图工作台”均进入同一画布；完成后点击“保存并回传资料”。在资料编辑窗口中回传后，还需保存资料本身。

默认把已有正文填入原有文字生成表单，正文为空时使用已有大纲。可切换“使用正文／使用大纲”；只有明确选择“重新从原附件生成”时才带入 PDF 或图片识别入口。用户确认“开始生成”后才提交模型任务。

文字生成可勾选“同时嵌入原讲义”：原 PDF 通过现有 stagePDF/addPDF 功能保存，保留字节及文件名，不上传到模型；按内容摘要去重。取消勾选时不读取原 PDF。文件保存失败会先报错，不继续提交模型。嵌入不自动生成正文段落与 PDF 页码的准确对应。其他格式仍可先在课程中提取为正文，或在导图界面选择支持的材料。

保存先正式保存导图文件与媒体，再回传课程 JSON。课程有其他窗口更新时保留新版课程与当前工作台草稿，提示冲突。旧版没有二进制附件的 JSON 不会凭空恢复缺失的原图。

## 预览边界

`preview.html?mode=preview` 只允许平移、缩放、适应窗口、全屏、详细／概览切换。屏蔽节点、连线、磁吸点、分组、学习清单、附件打开等其他操作。预览使用内存状态，不写正式文件、草稿或浏览器文档缓存。详细与概览复用原展示代码；不新增分支折叠功能。

## 接入层与更新

- `back/mindmapService.js`：统一网站下的接口和公开资源挂载；私有目录、CJS 文件不能作为静态文件读取。
- `js/course-settings.cjs`：把课程加密 AI 配置适配成导图服务已有的配置协议，后台任务沿用现有 IPC 配置传递。
- `js/course-host.js`、`css/course-host.css`：资料传入、保存回传、统一 AI 设置、只读交互与嵌入布局。
- `course.html`：完整单画布工作台入口，复用原脚本；`preview.html` 仅加载展示所需脚本。
- 原浏览器脚本中的 `/api/`、`/vendor/` 地址改为 `/mindmap/api/`、`/mindmap/vendor/`，媒体草稿令牌匹配规则同步调整。
- 编辑器核心仅增加只读修改守卫及只读内存缓存；`topic-ui.js` 导出原有 `panBy` 给只读手势使用。没有另写生成或主题布局算法。

后续升级先替换模块源文件，再核对上述适配点，勿覆盖个人数据或把原项目 `.local`、`storage` 一起复制。`integration-manifest.json` 记录本次源文件与部署文件摘要，方便比较。课程 `fronted/mindmap` 的旧副本已移到更新备份目录，运行时只有本目录这一份模块。

## 回归

项目根目录运行 `node tests/mindmap-integration.cjs`。测试会在临时目录复制代码，排除数据库、附件和密钥，使用随机端口及本地模拟模型，不调用真实平台。覆盖桌面和手机端、预览不变、完整生成链条、统一配置、媒体回传、重新打开及保存冲突。

## 正文与大纲的公式显示（2026-10-26）

课程详情直接复用本模块 MMContent.render（Markdown-it + KaTeX），支持行内及独立公式。正文、大纲和识别结果编辑框提供原文／预览切换。数据库继续保存原始 Markdown/LaTeX，不保存渲染 HTML；无效公式保留原文提示，关闭原始 HTML 执行，预览中的任务复选框禁用。相关课程适配位于 fronted/js/resourceRichText.js 与 fronted/css/resource-rich-text.css。


## 分组标题与重新生成（2026-10-26）

分组标题固定屏幕字号、内边距与边框，位置仍跟随分组；节点与底框按正常比例缩放。详细画布、资料详情预览、编辑资料预览和全屏共用同一实现，无实验开关。较长标题限制宽度并省略，悬停可查看完整标题。核心 applyView 同步缩放变量，PNG 导出副本重置为 100% 标签尺寸，避免受当前缩放影响。

详情页及资料编辑窗口增加“重新生成”：使用独立新导图 ID，仍通过模块原生成链条生成；回传前保留已有资料导图，关闭或生成失败不覆盖它。详情页“更多 → 移除导图”仅清空关联的 JSON / 图片，不清空正文、大纲和原附件，也不删除工作台文件。资料编辑窗口中的移除在保存资料后才生效。工作台继续向当前画布生成的入口改为“追加课程内容”，生成位置明确标为追加。

课程来源按钮未选中时具有浅底色和边框，选中时加深并显示勾选标记。核对选项改为“生成导图前，先确认正文与结构安排”，说明后台任务中确认后继续且规划会调用 AI；补充选项改为“允许 AI 添加补充解释（补充节点单独标明）”。
