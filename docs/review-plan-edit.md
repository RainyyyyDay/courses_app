# 复习计划编辑（2026-10-26）

计划列表卡片和计划详情提供“编辑计划”，复用创建计划弹窗，回填名称、考试日期及资料／笔记／错题的选择。开始日期保留原值。编辑时可以搜索、跨模块选题和预览；关闭或取消不保存。

仅改名称不改变排期。考试日期或内容范围实际变化时，弹窗先显示新增／移除数量，保存按钮显示“保存并调整剩余排期”。后端在同一事务中更新原计划及剩余任务，保留计划 ID、原任务 ID、已完成任务、会话、首次作答和评分证据。移出计划不删除源内容；再次加入复用原任务。普通完成当天任务仍不自动重排。

## 本地接口

`GET /api/courses/:courseId/review-plans/:planId` 详情返回不透明字符串 `editVersion`。编辑使用现有 `PATCH` 接口：

```json
{
  "name": "期末复习",
  "examDate": "2026-11-20",
  "selectedItems": [{"type": "material", "id": 1}, {"type": "note", "id": 2}],
  "expectedVersion": "从最近一次详情返回的 editVersion 原样传入"
}
```

编辑日期或范围必须提供版本；名称／归档的旧调用仍兼容。日期必须晚于原开始日期；调整排期时还须晚于北京时间今天，考试当天不安排任务。范围为 1～2000 项，不允许重复、跨课程或已不存在的内容。

计划参数、排期快照、任务进度或关联会话在编辑期间发生变化时返回 HTTP 409、`PLAN_VERSION_CONFLICT`。界面保留草稿，提示重新打开编辑，避免覆盖新状态。校验和保存失败整笔回滚。

本地通过已有排期 JSON 保存移出范围和已完成结果，不新增数据库字段。大组正式 Python／PostgreSQL 后端按此行为与接口约定接入；本次不实施大组鉴权或数据库集成。

## 验收

`tests/review-plan-edit.cjs` 使用临时数据库与独立后端，覆盖：仅改名不重排；日期变化；跨类型增删；移除及再次加入；已完成任务／历史证据保留；范围、日期和课程校验；事务回滚；任务完成或并发编辑导致的版本冲突；服务重启；未来开始和过期计划延期。

浏览器流程覆盖桌面和手机：创建后进入编辑、回填、取消、日期校验、跨模块选择、预览返回、失败保留、重复点击、立即重开、并发冲突和实际页面刷新。
