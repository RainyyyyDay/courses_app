真实草稿支持 standard/cloze/self_explain/contrast/reading，retry 仍复用已有任务、不另生成。三类内容使用相同编辑器：生成→独立可编辑预览→勾选人工核实→补空白/明确替换（可撤回）→原保存/开始流程。生成不改模式建议、正式材料、历史评分、会话或计划。内容不足返回具体缺项，不编造任务。

每次只发送编辑区当前题面（已挖空时还原已填写答案）及参考要点，不自动读取附件；每项最多 4000 UTF-16 单元，合计受请求体上限约束，过长须手动选段、不静默截断。草稿预览只在内存，正式保存前不入库；切换、取消、设置清除均不自动采用。

Python 新模块 `ai-fastapi/src/ai_material_draft.py` 提供 `register(app, dependencies=...)` 和 `POST /api/ai/material-draft`；只收发 JSON，不读数据库，不新增第三方依赖。不提供宿主鉴权依赖时默认拒绝。原材料 Mock 端点保持不变。

更新 Python 后需要手动重启现有 3002 AI 服务，再刷新页面；本轮没有停止或启动用户正在使用的原服务。
