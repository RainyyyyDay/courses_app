# 自定义 AI API

右下角“AI 设置” → 来源选择“自定义兼容接口” → 填写 API 地址、模型 ID 和 API Key → 确认发送与费用 → 应用设置。

- API 地址填写服务商文档中的 HTTPS 基础路径，例如 `https://服务商域名/v1`，或完整的 `/chat/completions` 地址。模型 ID 必须与服务商文档一致。
- 点击“测试已应用的连接”会发送一次固定虚构题目并校验模型回复，可能计费。默认 Key 仅下一次请求有效，测试也会消耗这次凭据；需要重复使用时勾选“在当前标签页保留 Key”。
- 支持 Chat Completions 兼容协议的文本 JSON 输出。适用于错题分析、答案草稿、资料/笔记复习建议、复习材料草稿和作答后 AI 批改。模型仍须满足各功能的结构化输出要求。
- 保留 DeepSeek 官方选项和默认 Mock 行为。自定义服务失败不会自动切回 DeepSeek 或 Mock，也不自动重试。
- 只支持公网 HTTPS，默认 443 端口；拒绝账号密码、查询参数、片段、内网/回环/特殊 IP 和重定向。每次解析全部 DNS 地址，全部为公网才可请求，并将连接固定到已检查的 IP，同时保留原域名的 TLS 验证。局域网模型服务暂不支持。
- Key 只在当前标签页内存及本次后端请求中使用，不写浏览器存储或数据库。刷新、关闭、清除或账号切换后失效。改变服务商或 API 地址后必须重新填 Key，避免误发旧密钥。
- 本次增加的是一个当前生效的自定义配置；不提供多个配置档案的持久化管理。其他原生协议、图片、工具调用及流式输出需要后续适配。

## 服务入口

推荐使用 `http://127.0.0.1:3000/`。一键启动会检查并启动本机 FastAPI（127.0.0.1:3002），3000 的本机专用转发入口把 AI 请求送到该服务，浏览器始终同源访问。也可继续使用 3002 页面。若手动只启动 Node，需另行启动 FastAPI；缺少服务时会明确提示。转发仅接受回环来源、本机 Host 和同源 Origin，拒绝转发头；正式宿主仍需接入认证授权，不应暴露本地测试服务。

## 验证

新增 `ai-fastapi/tests/test_compatible.py` 覆盖所有六类请求、传输协议、DNS 地址固定、内网和重定向拦截；`tests/ai-settings.cjs` 增加自定义配置的内存生命周期和桌面/手机浏览器检查。测试使用虚构 Key 和模拟上游，不产生真实模型费用。


## 超时和代理排查

真实模型请求最多等待 90 秒，Node 转发 95 秒、页面 100 秒，连接建立阶段最多 8 秒；不会自动重试。
如果域名被 FLClash/Mihomo 解析成 198.18.0.0/15 虚拟地址，将明确提示 Fake-IP，需为服务商域名配置真实 DNS 解析或关闭 TUN/Fake-IP。连接超时和模型响应超时分别显示。
一键启动的 AI 服务现在监听 src 目录变动并自动重载；升级此前启动的旧进程需要重启一次。


## 智谱和连接测试

普通 API 基础地址为 https://open.bigmodel.cn/api/paas/v4。模型 ID 必须为账号实际可用的型号；Coding Plan 的 Key 和权限需要与对应产品接口匹配。
自定义接口的连接测试只要求 {"connected":true}，不再执行完整错题分析。GLM 5 系列为思考和最终输出预留最多 8192 tokens，不自动重试。
失败时区分上游拒绝、模型不存在、权限不足、额度限制、输出截断、空回答和 JSON 格式问题。仅展示上游 HTTP 状态和数字业务码，不转发上游自由文本。
Windows 隐藏后台服务改由 local_runner.py 管理子进程，检测 src 修改后直接替换自身启动的 worker，避免 uvicorn 控制台信号重载卡住。已实际验证工作进程更换和 Mock 请求恢复。
