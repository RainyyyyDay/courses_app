# 资料／笔记复习片段保存（2026-10-22）

> 2026-10-24：资料/笔记详情页的旧“AI 复习建议”折叠入口已移除；本文保留为历史实现和存储兼容记录。

详情页“AI 复习建议”中的“待复习文字片段”提供独立的“保存复习片段”按钮，输入后显示未保存，成功后显示已保存并提供小提示。再次查看或刷新后进入同一条资料／笔记时，优先恢复明确保存的片段；没有保存记录时才使用正文或 OCR 文字，正文超4000字不静默截断。

沿用项目现有浏览器本地存储，通过课程、资源类型、条目 ID 隔离。只存版本号和片段，不存 Key、不调用 AI、不新增数据库字段、不修改原正文、已确认模式、正式材料、作答、评分或计划。确认模式不是保存片段；准备材料仍可使用当前输入，正式材料沿用原确认保存流程。

片段保存限制为非空、最多4000 UTF-16单元。保存后回读验证，存储失败时明确提示，保留当前输入和旧保存内容；不会显示虚假的成功。清理浏览器数据会丢失，换浏览器、设备或网站地址/端口不会同步。

学习目标与当前回忆／困难也可通过下方独立的“保存学习目标与回忆”按钮手动保存，并显示未保存／已保存状态。与片段分别存储，不覆盖已经保存的片段或复习方式；仍按课程、类型、条目隔离。目标只接受现有枚举，回忆最多4000 UTF-16单元，可留空或清空后保存。重新进入及刷新后恢复，只点击获取 AI 建议或确认模式不会顺便保存这两个输入。

验证：`node --test --test-name-pattern="saved resource review snippets" tests/resource-ai-text.cjs`。真实 Chrome 桌面/手机，使用虚构数据及临时数据库，覆盖直接查看、刷新恢复、类型/课程隔离、空/超长输入、存储失败、原正文及复习记录保护，不请求真实模型。建议接口回归见 `ai-fastapi/tests/test_resource_review.py`。
