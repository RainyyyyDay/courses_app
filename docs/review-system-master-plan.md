# 复习系统总路线（当前版）

更新：2026-10-19。本文只记录已经对齐的方向、当前实现和下一步顺序；不是一次性把所有功能都做完的承诺。

## 0. 一句话方向

**复习模式 = 练习动作 + 判分方式；排期只认 grade；AI 只生成/评价内容，不拥有排期。**

先做“能跑通的一条链”，再扩模式；不要在 OCR、PDF 标注、自动分类上提前消耗。

## 1. 当前已经落地

- 数据库 v17：错题增加 `question_format / options_json / correct_option / choice_type`，新增 `review_item_modes`。
- 选择题由**用户标明**：新建/编辑错题时选择“选择题”，填写至少两个选项和正确选项；默认仍是主观题。
- 选择题录入已改为系统编号：默认 A、B，点“＋ 添加选项”继续追加（最多 A–Z）；用户只填内容，正确答案只从已添加的字母里选；支持单选/多选，单选用 radio、多选用 checkbox，后端分别存单个字母或 JSON 数组。
- 没有自动检测题型、OCR 或 AI 识别选择题。只有结构化字段完整时，规则才自动解析为“选择复现”。
- 选择复现已打通：
  - 提交前不下发正确答案；
  - 选错 → 未复习、不完成计划任务；
  - 选对 → 已复习、记 Good；
  - 复习页可切换“选择复现 / 标准复习”，换模式保留记忆状态。
- 单独复习入口已下线：资料、笔记、错题不再有各自的“开始复习”入口；保留“总复习”和“考前计划”。
- 总复习完成弹窗已接管原错题完成弹窗和彩带：
  - 只显示实际选中的类别，0 项类别不显示；
  - 全部通过才飘彩带；
  - 取消 / 再来一遍 / 开始新复习。
- AI 门面已搭好，默认 mock：
  - `/api/ai/health`
  - `/api/ai/cloze`
  - `/api/ai/cloze/evaluate`
  - `/api/ai/evaluate-answer`
  - `/api/ai/recommend-mode`
- 排期快照仍只在用户点“应用新排期”时切换；同一天只提前复习一部分内容时，日历保留完整日排期。

## 2. 已经对齐的原则

1. 内容属性、错因、资料/笔记类型只用来**选模式**，不直接成为模式。
2. 选模式优先级：**用户明确选择 > 规则 > AI 建议**；AI 只对未确定内容给建议，用户确认后才生效。
3. 判分看“看答案前的首次作答”，不是看完解析后的自评。看过解析最多记 Hard，不直接给 Good。
4. 纯阅读是曝光，不是提取练习；不能默认给 Good，更不能默认给 Easy。
5. 排期只消费 `grade` 和 `durationMs`；模式不碰日期，AI 不碰排期。
6. AI 在创建计划/首次打开时生成产物并缓存；复习时只读缓存，失败降级到非 AI 版本。
7. 长资料先分块，复习单位是“章节/段落”，不是整份文档。
8. 挖空答案留在本地后端，前端只拿题面、空位 id 和提示。
9. 一次只打通一条垂直链；先客观模式，再 AI 模式，再 OCR/标注。
10. 完成度与掌握度分开：跳过、看了解析但答错，都不算“成功复习”。

## 3. 模式清单

| 模式 | 状态 | 适用 | 判分 | AI |
| --- | --- | --- | --- | --- |
| `choice_reproduction` 选择复现 | 已落地 | 有结构化选项和正确选项的错题 | 客观选择 | 不需要 |
| `standard` 标准复习 | 保留 | 其余错题 | 回忆/重做后自评 | 可选 |
| `cloze` 挖空回忆 | 下一步 | 记忆型内容 | 规则 + 语义等价 | 需要生成 |
| `self_explain` 自述讲解 | 待做 | 理解型内容 | 量规 + 自评/AI | 可选 |
| `reading` 阅读标记 | 待做 | “只想多看” | 曝光/一句话总结 | 不需要 |
| `contrast` 对比辨析 | 待做 | 易混概念 | 对比要点 | 可选 |

填空、自述、阅读不要各自写一套判分代码：内部收敛为客观选择、填空、开放作答三种判分引擎。

## 4. 下一步顺序

### 第 1 步：把“标明题型/用途”做成显眼步骤

当前问题：选择题字段藏在编辑弹窗里，用户不知道要标。

要补：

- 新建/编辑错题时，把“题型”放在题目卡片顶部，选择题直接展开选项和正确选项；
- 错题列表/详情显示“选择题 / 主观题”徽标；
- 老错题明确提示“未标注题型，当前按主观题复习”，并提供一键设置；
- 资料/笔记上传时增加“用途：记忆 / 理解 / 只想看 / 暂不确定”。

这一步不依赖 AI，也不依赖 OCR。

### 第 2 步：长资料分块 + 舒适阅读

- 文本/Markdown/DOCX/文本层 PDF 先提取为纯文本；
- 按标题/段落分块，建立“复习单元”；
- 阅读视图：约 760px 宽、17–18px 字号、1.8 行高、目录、进度；
- 暂不做扫描件 OCR，也不做 PDF 坐标高亮。

### 第 3 步：挖空 MVP

- AI 按块生成候选空位；
- 用户在预览里删除/保留/调整空位；
- 产物缓存，答案留后端；
- 判分先精确/别名，再加 AI 语义等价；
- 生成失败自动降级到“看题→自答→对答案”。

先做“AI 提议空位 + 用户调整”，不要一上来做完整划标系统。

### 第 4 步：自述讲解 / 对比辨析

- 先文字作答，不做语音/ASR；
- AI 给覆盖度建议，用户确认最终档位；
- 记录 AI 评价、自评、最终 grade，便于以后校准；
- “对比辨析”作为自述讲解的变体，不新增顶层模式。

### 第 5 步：AI 模式建议 + OCR/PDF 标注

- AI 只对“未分类/未确定”给模式建议，带置信度，用户确认；
- OCR 单独作为能力接入；
- PDF 坐标高亮、语音口述后置。

## 5. 现在不要做

- 自动检测选择题、自动识别资料/笔记类型；
- 扫描 PDF/照片 OCR；
- 完整 PDF 标注/划标编辑器；
- 五种模式同时开工；
- 让 AI 决定排期或完成度；
- 把云端地址、Key、答案写进前端。

## 6. 下一步一句话

**先把“题型/用途标明”做成用户看得见、点得到的步骤，再把长资料分块和挖空产物链打通；不要先做 OCR 或自动分类。**
