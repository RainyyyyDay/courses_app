# 公共确认框顶层修复

2026-10-21：材料编辑器的“替换表单”调用公共 showConfirm，但编辑器是 showModal() 原生模态框、确认框是普通 div 遮罩。原生模态框位于浏览器 top layer，普通遮罩即使提高 z-index 也无法盖过它，且会被视为不可交互背景。

修复：公共确认框改为原生 dialog，保留原 ID、确定/取消、showConfirm/closeConfirm 调用与兼容的 show 标记。每次确认在已有窗口之后进入顶层；取消或浏览器 cancel 事件仅关闭确认层，恢复触发按钮焦点，不关闭材料编辑器或清空输入。并发确认排队，避免覆盖前一个 Promise；仅明确确定返回 true。未改变任何业务保存或判分流程。

排查：搜索了全部 showConfirm 和 showModal 调用，涵盖材料草稿替换、课程/资源/知识点删除、题型/模式切换及计划删除；这些调用共用本次修复。除顶层确认外，不重写已修复的题型编辑逻辑。

浏览器测试：桌面1280×960、手机390×844，通过 elementFromPoint 检查两按钮实际处于可点击顶层；验证替换取消/确定/撤回、取消事件、返回焦点、正式材料未自动保存，以及嵌套 AI 设置、AI 原生窗口、旧编辑遮罩、普通队列确认。临时库评分/进度/会话/计划快照保持不变。已查看双视口截图。

命令：`node --test --test-name-pattern='confirmation top layer|format list/detail/edit' tests/confirm-dialog.cjs`，3/3通过（包含原有题型编辑双视口回归）。相关共享AI设置与原页复习回归另行执行；结果见本轮最终报告。语法及git diff --check通过。未读取.env、用户原库或调用真实模型；旧迁移测试不属于本次修复范围。
