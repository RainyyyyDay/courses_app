## 运行与调用关系

```text
浏览器页面
  → Node 3000 /api → back/db/index.js → SQLite / 本地附件
  → AI 适配层 → 本地 FastAPI 3002（默认 Mock；显式临时 Key 可调真实服务）
  → Node /api/ai/classify → 正式代理占位，目前缺认证，返回 503
  → Node 其他 AI 门面 → mock/http provider，部分演示端点固定 Mock
```

- 当前本机 3000 和 3002 首页均返回 200。3000 由 Express 托管静态前端；3002 由 FastAPI 托管并注入 AI 同源地址。抽查两者 `/js/reviewWorkbench.js` 均为 200 且与磁盘完全一致；不能据此认定内存中的所有后端路由都是最新版本。
- `start-local.ps1` 默认打开 3002，Node 仍走 3000；直接运行 Node 或双击 HTML 与这个入口的 AI 行为不同。未重启已有服务。
- `ai-service/` 是独立 Node AI 服务及 SCF/CloudBase 准备代码；不是当前本地 FastAPI 入口的替代品，也不能视为已上线云服务。
- `ocrBrowser.js` 已有浏览器端 OCR，资源在被 Git 忽略的 `fronted/vendor/ocr/`；另有 Node → 8001 Python 的备用路径。Python 依赖缺失不能直接推断浏览器 OCR 不可用。本轮未做真实 OCR 验收。
- 导图编辑器默认地址 `http://127.0.0.1:8794/`，有资料/笔记导图 JSON、图片保存和预览链路；完整编辑器运行验收需与负责组员协同。

## 已确认的问题（本轮不修改）

1. README 仍写数据库 v13、Node 不托管前端；实际为 v24 且 Node 已托管前端。
2. 标准回归首个迁移断言期望 v20，实际 v24，执行失败。多个迁移测试用字符串替换 `CURRENT_DB_VERSION = 20` 构造旧库，该字符串在当前代码已失效。不能只改预期数字就宣称迁移覆盖恢复。
3. 文档存在历史阶段混写：课程搜索文档仍有“前端未接入”，但页面已引用搜索脚本；复习总路线旧段落写用途选择/历史未做，最新代码已有学习目标与历史界面。
4. 前端 API 默认及部分附件链接写死 `localhost:3000`；导图默认 8794。统一部署前需明确唯一入口并验证全部资源路径。
5. 正式 AI 代理未接认证，前端新分析字段与该旧代理白名单也有差异；当前不能直接切换到正式代理代替本地服务。
6. 后端匿名接口、开放 CORS、裸附件访问、Multer 未统一限制大小；这些是多人上线前的实际缺口。
7. AI 建议/片段/上下文部分在 localStorage，临时 Key 在标签页内存。浏览器来源、设备或端口改变时不保证恢复；它们不等于数据库中的正式复习材料/轮次。
8. 不删除重复目录或历史模块：`ai-service` 与 `ai-fastapi` 用途不同；`db.js` 仍有测试引用。此前已 apply 的同步 stash 见 `sync-review-history-20261022.md`，不能重复 apply。
