# 站内附件预览

资料、笔记、错题题目/答案、复习内容预览及考核附件共用图片/PDF阅读窗口。图片可缩放、旋转和适应窗口，PDF按页渲染，可翻页、缩放、放大窗口；保留下载入口。其他格式只提供下载，不转换 Word/PPT。

读取附件不请求 OCR 或 AI，也不写数据库、评分或复习记录。复习答案仍由原有揭示流程决定是否显示。只接受当前站点或配置的 API 来源下的上传地址，以及当前站点生成的 blob 地址；不将任意外部网页嵌入为文档。

PDF复用项目现有的 pdfjs-dist 静态组件，按需加载，不新增 Python 依赖或云服务。交付前须包含 fronted/vendor/ocr/pdfjs/ 下的 pdf.min.js、pdf.worker.min.js 和许可证。静态产物不入 Git，可通过 `node tools/prepare-pdf-preview.cjs` 从已安装的 ocr-trial/node_modules/pdfjs-dist 复制，无需 OCR 模型。依赖未安装时先在 ocr-trial 安装其 package.json 对应依赖。完整 OCR 准备工具也会复制阅读组件。

加载失败、损坏/缺失文件或缺少阅读组件时提示下载。需要密码的 PDF 暂请下载到阅读器查看。PDF 本轮提供逐页画布阅读，不含全文搜索和文字复制。关闭或切换页面会释放任务；单页画布像素设上限，避免高分辨率页面占用过多手机内存。

自动检查使用临时数据库与真实上传的虚构图片、两页 PDF，覆盖桌面和手机、翻页/缩放、旋转/复位、错误、关闭切换、下载链接和不触发 AI；不读取实际用户文件。测试入口：tests/attachment-preview.cjs。


## PDF 文字识别

预览与文字识别相互独立。识别 PDF 时，所有附件识别入口共用页码弹窗：

- 默认全部页面，不再限制前 10 页；也可填写 `1-5, 8, 12-15`，重复页码会去重并按原文顺序处理。
- 页面存在可提取的文字层时直接读取，不启动 OCR；无文字层的扫描页逐页渲染、识别，随即释放画布。画布上限约 600 万像素。
- 显示当前页、完成页数和进度条。取消后不启动下一页；已经开始的 OCR 推理需要等待当前页结束。取消、失败不会改动正文或已有校对结果。
- PDF 失败或取消不会自动上传到服务端，避免服务端处理范围与用户选定页码不一致。图片仍保留原来的服务端回退。
- 结果保留页码标记，空白或无法识别的页会提示人工核对。纯文字提取不展示虚构的置信度；混合文档置信度仅统计 OCR 结果。
- 含部分文字层的图片混排页面只提取文字层，不额外识别图片里的文字；复杂排版的阅读顺序仍需人工校对。

验证：`node --test tests/pdf-ocr-pages.cjs tests/ocr-web-smoke.cjs tests/frontend-script-syntax.cjs`。27 页文字 PDF 用真实浏览器/pdf.js 测试；混合页、取消清理使用模拟页和识别器；真实 OCR 引擎另用合成图片测试。不调用付费 AI。
