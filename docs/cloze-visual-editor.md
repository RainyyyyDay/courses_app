# 选词挖空（2026-10-23）

## 使用

在资料、笔记或错题的“复习材料管理”中选择“挖空回忆”。输入或粘贴完整原文，选中文字后点击“选中文字并挖空”；选中文字自动成为答案。

- 点击彩色空位调整答案；其他可接受答案、提示在折叠设置中按需填写。
- 点击 × 取消挖空并恢复对应文字，撤销可恢复最近的编辑。
- 手机不方便选词时，展开备用入口，输入要挖的词并选择具体出现位置。
- “试做预览”隐藏答案、显示填空框；试填不保存、不产生轮次或评分。
- 最后确认保存；从原总复习或考前计划进入实际复习。

最多 20 个空位，单空答案最多 2000 字。重复词默认只挖选中的位置，不允许空位重叠。粘贴仅接受纯文本。原文可继续编辑；选区涉及已有空位时提示先取消对应空位，避免误改答案关联。
